A desktop management tool built with C#, WPF, and .NET Framework. Designed for local gym administration, this application streamlines client membership tracking, employee management, and access control with an offline-first SQLite database.

## Features

* **User Authentication** — Login system for gym staff and management.
* **Dashboard & Analytics** — Real-time metrics tracking active members, total subscriptions, and monthly growth.
* **Subscription Management** — Add, edit, and track gym member subscriptions and expiration status.
* **Employee Directory** — Manage gym employees details, roles, and salaries.
* **Search & Filtering** — Fast local querying for quick client and staff lookup.
* **Data** — Lightweight local data storage powered by SQLite.
* **Preferences** - Customizable app theme (Light/Dark mode) with automatic settings persistence

## Tech Stack

* **Language:** C#
* **Framework:** .NET Framework (WPF - Windows Presentation Foundation)
* **UI Architecture:** XAML with custom controls & styling
* **Database:** SQLite
